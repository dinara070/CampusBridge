# CampusBridge

Веб-платформа для управління студентськими хакатонами, челенджами та конкурсами.
Реалізовано на Python + Streamlit + SQLite (один файл `campusbridge.py`).

Головний заклад: **Вінницький державний педагогічний університет ім. М. Коцюбинського**,
факультет математики, фізики і комп'ютерних наук.

## Запуск

```bash
pip install -r requirements.txt
streamlit run campusbridge.py
```

Застосунок відкриється в браузері на `http://localhost:8501`.
База даних `campusbridge.db` (SQLite) створюється автоматично при першому запуску.

## Обліковий запис адміністратора за замовчуванням

- Логін: `admin`
- Пароль: `admin123`

Облікові записи журі створює лише адміністратор (розділ «⚖️ Журі»).
Учасники реєструються самостійно на вкладці «Реєстрація учасника» — доступ
підтверджується автоматично за корпоративною поштою (наприклад, `@vspu.edu.ua`).

## Ролі та можливості

**Адміністратор**
- Конструктор подій: типи подій, номінації, критерії оцінювання, дедлайни, статуси.
- Модерація заявок команд: індивідуальні та масові дії, коментарі.
- Керування журі: створення акаунтів, розподіл за номінаціями, конфлікт інтересів.
- Аналітика: графіки за подіями/факультетами/статусами, виявлення аномальних оцінок.
- Сповіщення: глобальні та таргетовані на конкретну команду.
- Імпорт/експорт: CSV та Excel для подій, команд, оцінок, користувачів.

**Учасник / капітан команди**
- Перегляд календаря подій із фільтрами.
- Створення команди (інвайт-код) або приєднання за кодом.
- Подача проєкту: посилання на репозиторій/відео, PDF-презентація (до 50 МБ),
  версіонування подачі, трекінг статусу.
- Перегляд публічного лідерборду та оголошень.

**Журі / експерт**
- Список призначених команд з матеріалами проєкту.
- Матриця оцінювання за критеріями (слайдери) + текстовий фідбек.
- Автоматична блокировка оцінювання команд свого факультету (конфлікт інтересів).

## Примітка щодо зберігання файлів

Для спрощення розгортання презентації (PDF) зберігаються як BLOB у SQLite
(до 50 МБ), а не в S3 — це легко замінити на хмарне сховище пізніше без
зміни решти логіки.
