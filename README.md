# CampusBridge

Веб-платформа для управління студентськими хакатонами, челенджами та конкурсами.
Реалізовано на Python + Streamlit + SQLite (один файл `campusbridge.py`).

Головний заклад: **Вінницький державний педагогічний університет ім. М. Коцюбинського**,
факультет математики, фізики і комп'ютерних наук.

## Запуск

```bash
pip install -r requirements.txt
streamlit run campusbridge.py
```

Застосунок відкриється в браузері на `http://localhost:8501`.
База даних `campusbridge.db` (SQLite) створюється автоматично при першому запуску.

При розгортанні на **Streamlit Community Cloud** платформа автоматично встановить
системний пакет із `packages.txt` (`fonts-dejavu-core`) — він потрібен, щоб PDF-протокол
журі коректно відображав кирилицю.

## Тестові облікові записи (створюються автоматично при першому запуску)

| Роль | Логін | Пароль |
|---|---|---|
| Адміністратор | `admin` | `admin123` |
| Журі | `jury_demo` | `jury123` |
| Ментор | `mentor_demo` | `mentor123` |
| Учасник | `participant_demo` | `part123` |

Ці ж дані показані у застосунку на сторінці входу (розкривний блок «🔑 Демо-облікові
записи»). Нові акаунти журі та менторів адміністратор надалі створює через розділи
«⚖️ Журі» і «🧑‍🏫 Ментори». Учасники також можуть реєструватися самостійно на вкладці
«Реєстрація учасника» за корпоративною поштою (наприклад, `@vspu.edu.ua`).

## 📅 Календар подій — можливості

- **Пошук і сортування:** текстовий пошук за назвою, описом і регламентом; сортування
  за найближчою датою старту або за розміром призового фонду.
- **Інтерактивна календарна сітка:** вкладка «🗓️ Календарна сітка» показує події
  на місячному/тижневому календарі (компонент `streamlit-calendar`), з окремими
  позначками старту реєстрації, старту події та дедлайну пітчингу.
- **Кнопка «Додати в календар»:** для кожної події можна завантажити `.ics` файл
  з усіма ключовими дедлайнами (старт/кінець реєстрації, старт хакатону, дедлайн
  пітчингу) — файл відкривається одним кліком у Google Calendar, Outlook, Apple Calendar.
- **Банери та промо-відео:** адміністратор може додати посилання на банер (URL
  зображення) і промо-відео (YouTube) при створенні/редагуванні події — вони
  відображаються на картці події та в окремому блоці «🎬 Промо-відео».

## 🏆 Лідерборд і портфоліо — можливості

- **Деталізація по критеріях (Breakdown):** у кожного місця в лідерборді є вкладка
  «🔍 Деталізація балу» з розгорткою — середній бал за кожним критерієм (з урахуванням
  ваги та внеску у підсумок), а також таблиця індивідуальних оцінок і фідбеку від
  кожного члена журі окремо.
- **Офіційний протокол журі (PDF):** адміністратор і журі бачать кнопку «📄 Завантажити
  офіційний протокол журі (PDF)» — генерується таблиця результатів (команда, бали за
  критеріями, підсумковий бал, місце), список складу журі з місцем для підпису,
  рядки для голови журі та печатки. Кирилиця в PDF рендериться шрифтом DejaVu Sans
  (для Streamlit Community Cloud додано `packages.txt` з `fonts-dejavu-core`; якщо
  шрифту немає на сервері, застосунок автоматично транслітерує текст, щоб PDF
  не зламався).
- **Публічне портфоліо проєктів (Showcase):** окрема сторінка «🖼️ Портфоліо проєктів»
  доступна всім ролям і навіть без входу — галерея командних проєктів (репозиторії,
  демо-відео, презентації) з фільтром «лише завершені (архів)» та пошуком, з позначкою
  🏆 для проєкту-переможця кожної події.
- **Фільтрація за номінаціями:** у лідерборді можна звузити таблицю до однієї номінації
  події (наприклад, лише трек «AI / Machine Learning»).
- **Анімовані картки призерів:** топ-3 команди показуються окремим «п'єдесталом» із
  золотою/срібною/бронзовою CSS-анімацією (плавна поява + пульсуюче світіння).
- **Порівняння команд:** можна обрати 2-4 команди й побачити їхні середні бали по
  кожному критерію та підсумковий результат поруч, в одній таблиці.
- **Експорт повної аналітики (CSV/Excel):** кнопка прямо на екрані лідерборду формує
  таблицю «місце, команда, факультет, бал по кожному критерію, підсумковий бал» і
  одразу пропонує завантажити її в CSV або Excel.
- **Інтерактивні графіки:** три вкладки — підсумкові бали команд, розподіл середніх
  балів за критеріями (згруповані стовпчики) і гістограма розподілу всіх
  індивідуальних оцінок журі — усе на Altair-графіках з підказками при наведенні.

### Портфоліо (Showcase) — картки, теги, лайки, inline-перегляд

- **Картковий дизайн (grid-view):** проєкти показані сіткою 3 картки в ряд, кожна з
  назвою, факультетом, балом, тегами технологій і коротким описом.
- **Пошук за технологіями/тегами:** команда вказує теги (наприклад, `Python, React,
  PostgreSQL`) при подачі проєкту; у портфоліо є текстовий пошук і мультивибір тегів
  для фільтрації.
- **Лайки глядачів (Community Choice Award):** будь-який відвідувач (навіть без
  входу — голос прив'язується до анонімної сесії) може натиснути ❤️; проєкт із
  найбільшою кількістю лайків отримує позначку Community Choice.
- **Перегляд PDF-презентацій прямо в інтерфейсі:** презентація рендериться інлайн
  через вбудований переглядач (без обов'язкового завантаження файлу), з окремою
  кнопкою «Завантажити» для тих, кому потрібна копія.
- **Модальні вікна з розширеним прев'ю:** кнопка «🔍 Детальніше» відкриває спливаюче
  вікно (`st.dialog`) з повним описом, тегами, відео, презентацією та кнопкою лайка.

## 🛠️ Конструктор подій — можливості

- **Шаблони подій:** розділ «🧩 Створити на основі шаблону» пропонує готові налаштування
  для класичного хакатону, кейс-чемпіонату та спортивного челенджу — категорія, формат,
  розмір команди, номінації, критерії оцінювання з вагами та типовий ліміт команд
  застосовуються в один клік і повністю редаговані перед збереженням.
- **Гнучке налаштування журі на рівні події:**
  - 🕶️ *Сліпе оцінювання* — журі не бачить назву команди й факультет (детальніше вище).
  - 👀 *«Журі бачать оцінки одне одного»* — якщо увімкнено, кожен експерт бачить бали
    й фідбек колег по цій самій команді прямо під час оцінювання (прозорий процес);
    якщо вимкнено — кожен оцінює незалежно.
- **Ліміти та автоматичне закриття:** адміністратор може задати максимальну кількість
  команд-учасниць. Щойно ліміт вичерпано (при реєстрації нової команди учасником,
  масовому імпорті команд або редагуванні ліміту адміністратором), подія автоматично
  переходить у статус «Закрито», і форма реєстрації нових команд для неї зникає.
  Прогрес заповнення команд видно і в календарі, і в конструкторі подій.

## Ролі та можливості
**Адміністратор**
- Конструктор подій: типи подій, номінації, критерії оцінювання, дедлайни, статуси.
- Модерація заявок команд: індивідуальні та масові дії, коментарі.
- Керування журі: створення акаунтів, розподіл за номінаціями, конфлікт інтересів.
- Аналітика: графіки за подіями/факультетами/статусами, виявлення аномальних оцінок.
- Сповіщення: глобальні та таргетовані на конкретну команду.
- Імпорт/експорт: CSV та Excel для подій, команд, оцінок, користувачів.

**Учасник / капітан команди**
- Перегляд календаря подій із фільтрами.
- Створення команди (інвайт-код) або приєднання за кодом.
- Подача проєкту: посилання на репозиторій/відео, PDF-презентація (до 50 МБ),
  версіонування подачі, трекінг статусу.
- Перегляд публічного лідерборду та оголошень.

**Журі / експерт**
- Список призначених команд з матеріалами проєкту.
- Матриця оцінювання за критеріями (слайдери) + текстовий фідбек.
- Автоматична блокировка оцінювання команд свого факультету (конфлікт інтересів).
- **Сліпе оцінювання (double-blind):** якщо в налаштуваннях події увімкнено цю опцію,
  журі бачить лише анонімний код команди (наприклад, «Команда №A1B2») замість назви
  та факультету. Захист від конфлікту інтересів за факультетом продовжує діяти
  автоматично навіть у сліпому режимі.

**Ментор**
- Обліковий запис створює адміністратор (розділ «🧑‍🏫 Ментори»).
- Створює слоти для коротких онлайн-консультацій (Office Hours) прив'язані до події:
  дата, час початку/кінця, місце проведення (Zoom/Meet/офлайн), примітка.
- Бачить свій розклад і статус кожного слота (вільно / заброньовано, якою командою).
- Може видалити ще не заброньований слот.

**Учасник — Office Hours**
- На вкладці «🗓️ Office Hours» команда бачить список вільних слотів консультацій
  менторів для своєї події та може записатись у 1 клік.
- Показується поточний запис (ментор, дата, час, місце) з можливістю скасування,
  після чого слот знову стає вільним для інших команд.

## Примітка щодо зберігання файлів

Для спрощення розгортання презентації (PDF) зберігаються як BLOB у SQLite
(до 50 МБ), а не в S3 — це легко замінити на хмарне сховище пізніше без
зміни решти логіки.
